# Rust 远程运维工作台：独立产品开发规范

## 1. 文档控制

- 状态：可进入原型实现。
- 实现语言：Rust；桌面优先 Windows，核心协议和数据层跨平台。
- 产品代号建议：`FinalPowerShell`，不代表 FinalShell 官方产品。
- 目标：提供安全、可测试的多会话 SSH 工作台，而不是复制专有实现。
- 兼容边界：不要求读取原程序配置、兼容原云服务或复刻原 UI。

## 2. 产品原则

1. 本地优先：离线时可完成连接、终端和文件操作。
2. 凭据隔离：密码和私钥口令不进入普通配置、日志、历史、崩溃报告或默认导出。
3. 显式行为：远程命令、覆盖、删除、抓包、同步和更新均有明确范围。
4. 响应式：网络或文件 I/O 不阻塞 UI，所有长任务可取消。
5. 可恢复：断线、失败传输和损坏设置不得丢失既有有效数据。
6. 增量交付：SSH 终端和 SFTP 先于云同步、抓包、平台扩展。

## 3. 角色与核心场景

### 3.1 角色

- 运维人员：管理多个服务器、执行命令、传输文件、查看状态。
- 开发人员：通过 SSH 使用开发机、编辑远程文本、复用命令片段。
- 高级用户：配置密钥、代理、跳板、转发，按授权使用诊断工具。

### 3.2 P0 用户旅程

#### A. 创建并保存连接

1. 用户创建文件夹或选择现有文件夹。
2. 输入名称、主机、端口、用户名和认证方式。
3. 密码认证由密钥库保存密码；私钥认证只保存私钥路径和密钥库口令引用。
4. 首次连接显示主机密钥指纹，用户选择信任、仅本次或取消。
5. 系统持久化非敏感配置，成功后列入可筛选的连接树。

验收：重启后连接资料可用；普通配置、UI 日志和导出文件不含密码或私钥口令。

#### B. 使用交互式终端

1. 用户打开一个或多个会话标签。
2. 状态依次为连接中、认证中、已连接、断开/失败。
3. 用户调整终端尺寸，输入 UTF-8 字节流并接收增量输出。
4. 支持选择复制、粘贴、滚动、清屏、查找和编码配置。
5. 远端 EOF 与本地主动关闭显示不同原因；用户可显式重连。

验收：交互命令、ANSI 样式和窗口调整可用；断开不导致 UI 卡死或其他标签退出。

#### C. 浏览和传输文件

1. 用户在会话中打开 SFTP 面板。
2. 系统展示目录、名称、类型、大小、修改时间和可用权限。
3. 用户上传/下载文件或目录，看到队列、速度、已传输字节、失败原因。
4. 覆盖前显示源/目标信息；任务支持暂停、继续（协议支持时）和取消。
5. 使用同目录临时文件加原子替换，避免失败覆盖破坏原文件。

验收：传输进度来自实际字节计数；取消清理临时文件；远端目录切换不影响其他会话。

#### D. 管理命令片段与历史

1. 用户创建分组和命令片段，标记是否含敏感参数。
2. 可发送到当前会话；多会话广播必须单独确认并展示目标。
3. 历史可搜索、删除、清空、禁用。
4. 多行或高风险命令发送前提供预览。

验收：不会在用户不知情时向所有会话发送；历史关闭后不追加新记录。

## 4. 功能需求与优先级

### P0：核心版本

- 连接分组、增删改查、复制、搜索和导入导出。
- SSH 密码/公钥认证、主机密钥验证、会话状态与手动重连。
- 多标签终端、ANSI/VT 解析、滚动缓冲、尺寸变化、剪贴板。
- SFTP 目录浏览、文件/目录上传下载、任务队列、取消与覆盖确认。
- 本地设置、主题、字体、快捷键、布局和路径偏好。
- 密钥库集成、原子设置写入、备份和恢复。
- 命令历史与分组片段。

### P1：效率增强

- 远程文本编辑、修改检测、保存失败恢复。
- SSH 跳板、HTTP/SOCKS 代理、本地/远程端口转发。
- CPU、内存、磁盘、网络和进程监控；明确刷新周期。
- 多会话输入广播、命令补全、输出搜索与会话导出。
- 系统托盘、关闭确认、下载目录与编辑器自定义。

### P2：可选扩展

- 显式同步：配置、片段、删除墓碑和冲突处理。
- 网络探测、授权抓包、IP 数据查询。
- 插件化协议：本地 Shell、串口或其他明确需求驱动的新协议。
- 签名更新、安装器与自启动。

## 5. 状态与规则

### 5.1 会话状态

`Disconnected -> Connecting -> Authenticating -> VerifyingHost -> Connected -> Reconnecting/Closing -> Closed/Failed`

- 每次状态变化包含会话 ID、时间和可读原因。
- 自动重连只能复用原有授权范围，采用指数退避和上限。
- 主机密钥变化必须阻止静默重连。

### 5.2 传输状态

`Queued -> Running -> Paused -> Completed/Failed/Cancelled`

- 传输使用稳定任务 ID；重试不得重复报告已确认字节。
- 远端错误、磁盘不足、权限不足和取消分别呈现。
- 删除、递归覆盖等操作要求显示精确目标路径。

### 5.3 配置状态

- 配置具有 `schema_version`，加载时先验证再迁移。
- 迁移前创建备份；失败时使用最近有效配置，不删除用户数据。
- 普通导出只含非敏感资料；敏感导出默认禁用且必须二次确认。

## 6. 非功能验收

| 类别 | 要求 |
| --- | --- |
| 响应性 | 所有网络和文件任务异步；UI 不等待完整目录或大文件加载 |
| 背压 | 终端和传输事件有界；高速输出不能无限占用内存 |
| 隔离 | 一个会话失败不得关闭其他会话或破坏全局配置 |
| 安全 | 默认验证 TLS/SSH 主机身份；敏感字段零日志、零普通导出 |
| 可测试 | 协议、存储、状态机不依赖 GUI；使用本地伪终端和临时服务器测试 |
| 跨平台 | 核心支持 Windows/Linux；平台凭据库和进程能力通过适配器实现 |
| 可维护 | 禁止 UI 直接调用 SSH/SFTP SDK；统一错误类型与结构化事件 |
| 资源清理 | 会话、任务、抓包与本地进程均具有显式关闭和超时 |

## 7. 明确不做

- 不绕过原程序授权、许可证或安全控制。
- 不复制原程序混淆代码、私有协议或商标资源。
- 不默认兼容原配置文件或原云同步服务。
- 不在未授权服务器上抓包、扫描或执行命令。
- 不在第一版同时承诺所有协议、云同步和跨平台安装器。

## 8. 里程碑与完成定义

### M1：协议与存储骨架

实现领域类型、连接 CRUD、密钥库、主机密钥策略、设置迁移和状态机；全部具有单元测试。

### M2：可用终端

完成 SSH、多标签 VT 终端、认证、主机指纹和断线处理；通过本地 SSH 测试环境验收。

### M3：文件与命令

完成 SFTP 浏览、传输队列、历史、片段和基础工作台；通过取消、覆盖和磁盘错误测试。

### M4：增强功能

按用户实际优先级实现远程编辑、监控、代理和隧道，每项独立验收，不同时扩张范围。
